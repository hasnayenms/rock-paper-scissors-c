🎮 Rock, Paper, Scissors — C Project

A console-based Rock, Paper, Scissors game developed in C while learning programming with Programiz PRO.

📌 Project Overview

This project is a classic Rock, Paper, Scissors game where a player competes against the computer. It uses random computer choices, score tracking, and conditional logic to determine the winner.

✨ Features

- 🎮 Classic Rock, Paper, Scissors gameplay
- 🎲 Random computer choices
- ⌨️ Supports full choice names and "r/p/s" shortcuts
- ✅ Invalid input handling
- 🏆 Round-by-round score tracking
- 📊 Final score and match result

🚀 Additional Features I Implemented

1. Customizable Number of Rounds

Players can choose how many rounds they want to play before the game starts.

2. Optional Sudden Death Tie-breaker

Players can choose whether to enable Sudden Death before starting the game. If the final scores are tied, the game enters a tie-breaker phase and continues until one player wins a round.

📚 What I Learned

Through this project, I practised:

- Functions and modular programming
- Arrays and strings
- Conditional statements ("if-else")
- Loops ("for" and "while")
- Random number generation using "rand()" and "srand()"
- String handling using "strcmp()" and "strcpy()"
- User input handling with "scanf()"

▶️ How to Run

This project can be compiled and executed using a compatible C compiler, such as GCC, Code::Blocks, or an online C compiler.

1. Download or copy "main.c".
2. Open the file in a C compiler or IDE.
3. Compile and run the program.
4. Enter the desired number of rounds.
5. Choose whether to enable the Sudden Death tie-breaker.
6. Enter "rock", "paper", "scissors", or use "r", "p", "s" to play.
